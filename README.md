# erase-me：让 AI 忘掉你

一个 Agent Skill（`SKILL.md` 格式），给**准备彻底离开某个 AI 助手**的人用。

你走之前，它在你自己的账号里做两件事：

1. **删改**：能直接编辑账号记忆的，按你的选择删掉或改写。
2. **覆盖**：助手和自己进行多轮对话，扮演一个虚构的人，一轮一轮把这个人的人生往好的方向写，让云端记忆被虚构内容占满，真实的你被稀释掉。

它不碰你电脑上的任何文件。

## 它会先问你

1. 深度：

| 深度 | 已有记忆 | 循环对话写什么 |
|---|---|---|
| A. 清空 | 全部删除 | 与任何人无关的中性话题 |
| B. 只留美好 | 删掉难受、尴尬、敏感的，留下开心的 | 顺着美好的部分往好处写 |
| C. 虚构身份 | 全部删除 | 一个虚构的人，一轮一轮过得越来越好 |

2. 虚构身份你来定，还是让它编（名字、年龄、城市、职业、爱好）
3. 循环几轮：默认 20，最多 100
4. 有没有一定要盖掉的话题

删改记忆前会先给你看预览，你说"确认"才动手。

## 先读：它能做到多少

| | 能做到 | 做不到 |
|---|---|---|
| 账号记忆 | 平台给了记忆编辑工具时，真删、真改 | 没有工具就只能告诉你去设置页删 |
| 循环覆盖 | 让平台的记忆功能更多地记住虚构的人 | **覆盖不是删除**：原来的聊天记录、服务器日志、备份都还在；平台怎么生成记忆由平台决定，效果没法保证 |
| 其他 | | 已用于训练的数据、其他账号 |

几点提醒：

- 只在**开着记忆功能的网页版 / App 对话**里有效。在命令行或编辑器里的 agent 里跑，会话不进账号记忆，没效果。
- 很耗 token，每轮几百个，100 轮就是几万。
- 虚构身份不会用真人、公众人物或你身边的人。
- 它不会用脚本、API 或多个账号批量刷对话，那样违反服务条款。
- 想真正删掉云端内容，还是要自己动手：Claude 在 设置 → 隐私 / 记忆，ChatGPT 在 设置 → 个性化 → 记忆 → 管理，再删掉相关聊天；服务器日志按服务商隐私政策申请删除。准备注销账号的，注销通常会删掉更多数据。

## 安装

技能要在网页版 / App 里跑才有效：

- **Claude 网页版 / App**：把仓库打包成 zip，在 设置 → 功能 里上传为技能（需要所在套餐支持自定义技能）。
- **不支持技能的平台**（如 ChatGPT）：新开对话，把 `SKILL.md` 的全文贴进去，再说"按这个做"。

在命令行工具（Claude Code、Codex 等）里也能装，但那里只能帮你做准备（问清需求、编好身份卡），覆盖要去网页版 / App 跑：

```bash
npx skills add youneedhelp111/erase_me
```

## 使用

在网页版 / App 新开对话，说：

- "我不用你了，把我抹掉"
- "用假身份覆盖我的记忆，跑 50 轮"
- "erase me"

跑完后，把一开始回答需求的那段对话删掉，只留覆盖用的对话。

## 进化记录

这个技能用 [darwin-skill](https://github.com/alchaincyf/darwin-skill) 的流程优化过：沙盒里用假记忆跑测试，每轮改动由 3 个独立评审盲比改前改后，多数判好才保留。结果在 [darwin/results.tsv](darwin/results.tsv)，测试用例在 [test-prompts.json](test-prompts.json)。之后按需求改成了只处理云端，本地扫描脚本已删除。
