# erase-me：让 AI 忘掉你

一个 Agent Skill（`SKILL.md` 格式）。在你自己的账号里做两件事：

1. **改写，不删除**：找出 AI 记住的敏感内容，你确认后改写成去掉细节、仍然属实的笼统说法。比如"三天前咨询性病检测，起因是婚外情"改成"咨询过一个健康方面的问题"。
2. **稀释**：改完以后，助手用多轮与你无关的中性话题问答（天文、烹饪、历史……）把记忆冲淡。

改写只往上概括，不加原文没有的事实。它不编造身份，不以你的口吻写话，也不往记忆里写指令。除了一份可选的 Excel 对照表，它不碰你电脑上的任何文件。

## 前提：你已经自己删过聊天

技能默认你已经尽力删掉了相关的聊天。还没删的话，入口在这里（可选，不影响技能运行）：

- Claude：侧栏聊天记录 → 对话右侧"…" → 删除；设置 → 隐私 / 记忆
- ChatGPT：侧栏 → 对话右侧"…" → 删除（也查"已归档的对话"）；设置 → 个性化 → 记忆 → 管理

聊天标题本身也可能暴露内容。没删的聊天记录，技能改变不了。

## 它会先问你

一条消息问完，也可以说"你决定"：

1. 范围：A 全部模糊（每条都改成笼统说法） / B 只改敏感的，其他原样留着
2. 改完稀释几轮：0 表示不稀释，默认 10，最多 100
3. 要不要生成 Excel 对照表，存在哪里，要不要加密码

## 流程

1. 读出 AI 记得的你，逐条编号、分类、定级（强隐私 / 一般 / 无）。清单里强隐私条目只写"（不复述）"
2. 给你看每条要改成什么（强隐私的原文仍然不复述），你说"确认"才改
3. 有记忆工具就直接用"更新"改写并复查；平台只能删不能改时，先问你是删还是保持原样；没有工具就告诉你去设置页怎么改
4. 中性话题稀释 N 轮，助手以自己的身份问答，不提你，不碰被改写的话题
5. 核验：从每条原文取几个关键词，在改写后的记忆和 AI 的自述里查有没有残留，有就再概括一层
6. 报告改了几条、留了几条、稀释几轮、核验结果

## 可选：Excel 对照表

分两次写入同一个文件：

1. **改写前**：写入原始记忆（编号、类别、敏感级别、原文）
2. **结束后**：写入改写后的记忆，再生成"对照"（原文和改写后并排）和"核验"（每个关键词有没有残留）

保存位置由你选，可以加密码（装了 `msoffcrypto-tool` 时自动加密，没装就提示你在 Excel 里用"文件 → 信息 → 保护工作簿 → 用密码进行加密"）。

**风险要先说清楚：这个表本身就是一份写着你原始内容的明文记录。** 云端删得再干净，电脑上留着它也一样会被看到。所以：

- 不需要就选"不生成"
- 要生成就加密码，存在只有你知道的地方
- 看完就删掉，并清空回收站

脚本是 `scripts/memory_report.py`，只用 Python 自带的库，数据从标准输入传入，不留中间文件。

## 它能做到多少

| | 能做到 | 做不到 |
|---|---|---|
| 账号记忆 | 平台给了记忆编辑工具时，直接改写 | 没有工具就只能告诉你去设置页改；有的平台只能删不能改，会先问你 |
| 中性稀释 | 让记忆里与你无关的内容变多 | **稀释不是删除**：聊天记录、服务器日志、备份都还在；平台怎么生成记忆由平台决定，效果没法保证 |

- 只在**开着记忆功能的网页版 / App 对话**里有效，命令行或编辑器里的 agent 没效果
- 耗 token，每轮稀释几百个
- 不用脚本、API 或多个账号批量刷对话，那样违反服务条款
- AI 拒绝执行某一步时，技能会停下来告诉你原因，不会绕过
- 服务器日志只能按服务商隐私政策申请删除；注销账号通常会删掉更多数据

## 安装

技能要在网页版 / App 里跑才有效：

- **Claude 网页版 / App**：把仓库打包成 zip，在 设置 → 功能 里上传为技能（需要所在套餐支持自定义技能）。
- **不支持技能的平台**（如 ChatGPT）：新开对话，把 `SKILL.md` 的全文贴进去，再说"按这个做"。

在命令行工具（Claude Code、Codex 等）里也能装：

```bash
npx skills add youneedhelp111/erase_me
```

## 使用

在网页版 / App 新开对话，说：

- "把我抹掉"
- "把我上周问的那件事改模糊，再稀释 10 轮"
- "erase me"

跑完后，把这段对话删掉。

## 进化记录

这个技能用 [darwin-skill](https://github.com/alchaincyf/darwin-skill) 的流程优化过：沙盒里用假记忆跑测试，每轮改动由 3 个独立评审盲比改前改后，多数判好才保留。结果在 [darwin/results.tsv](darwin/results.tsv)，测试用例在 [test-prompts.json](test-prompts.json)。后来按需求改成只做改写（不删除）和中性稀释，去掉了虚构身份和渐进漂移。
