# erase-me：让 AI 忘掉你

一个 Agent Skill（`SKILL.md` 格式）。在你自己的账号里，让 AI 对你的记忆一轮一轮变成另一个人，敏感的事被换成不敏感的事。适合准备离开某个 AI，或想盖掉某段敏感记忆的人。

除了一份可选的 Excel 对照表，它不碰你电脑上的任何文件。

## 前提：你已经自己删过

技能默认你已经尽力删掉了相关的聊天和记忆条目。即便这样，AI 仍可能从剩下的上下文里推断出那件事，技能处理的就是这部分。

还没删的话，入口在这里（可选，不影响技能运行）：

- Claude：侧栏聊天记录 → 对话右侧"…" → 删除；设置 → 隐私 / 记忆
- ChatGPT：侧栏 → 对话右侧"…" → 删除（也查"已归档的对话"）；设置 → 个性化 → 记忆 → 管理

聊天标题本身也可能暴露内容，漂移改变不了没删的聊天记录。

## 渐进漂移

技能先把 AI 记得的你整理成一份"第 0 轮档案"，再规划一张漂移路径表给你确认。之后每一轮只对上一轮微调几处，像是你在"更正"之前说过的话：

| 轮 | 名字 | 职业 | 收入 | 学历 | 孩子 | 敏感事件 |
|---|---|---|---|---|---|---|
| 0 | 李三 | 设计师 | 30 万 | 清华 | 3 | 咨询性病检测（强隐私） |
| 1 | 李四 | 设计实习生 | 18 万 | 北大 | 3 | 咨询酒精检测（一般） |
| 2 | 张四 | 设计院财务 | 18 万 | 浙大 | 1 | 咨询怎么维持友情（无） |
| 3 | 张四 | 设计院财务 | 18 万 | 浙大 | 1 | 删除，换成周末学做饭 |

规则：

- 强隐私事件优先处理，每轮降一级（强隐私 → 一般 → 无 → 删除），绝不换成同样或更敏感的事
- 身份字段一个个换，最后一轮全部和真实的你不同
- 有记忆工具时，每轮用"更新"改写对应条目，记忆里只留最新一版
- 跑完会自查"你记得我是谁？"，对不上就补几轮

另外两种深度：**A 全部清空**（删掉全部记忆，只写中性话题），**B 只留美好**（身份不动，只把敏感事件降级后删掉）。

轮数由你定：默认 10，最多 100。不会无限循环。

## 可选：Excel 对照表

开始前它会问你要不要在电脑上生成一份 Excel，分两次写入同一个文件：

1. **漂移开始前**：写入原始记忆（编号、类别、敏感级别、原文）
2. **所有轮跑完后**：写入修改后的记忆，再生成"对照"和"核验"两张表。"对照"一行一条，原文和最终内容并排；"核验"列出每件敏感事件的关键词有没有残留

保存位置由你选，可以加密码（装了 `msoffcrypto-tool` 时自动加密，没装就提示你在 Excel 里用"文件 → 信息 → 保护工作簿 → 用密码进行加密"）。

**风险要先说清楚：这个表本身就是一份写着你原始秘密的明文记录。** 云端删得再干净，电脑上留着它也一样会被看到。所以：

- 不需要就选"不生成"
- 要生成就加密码，存在只有你知道的地方
- 看完就删掉，并清空回收站

脚本是 `scripts/memory_report.py`，只用 Python 自带的库，数据从标准输入传入，不留中间文件。

## 它能做到多少

| | 能做到 | 做不到 |
|---|---|---|
| 账号记忆 | 平台给了记忆编辑工具时，真删、真改 | 没有工具就只能带你去设置页删 |
| 渐进漂移 | 让 AI 的记忆指向另一个人、另一件不敏感的事 | **不是删除**：聊天记录、服务器日志、备份都还在；平台怎么生成记忆由平台决定，效果没法保证 |

- 只在**开着记忆功能的网页版 / App 对话**里有效，命令行或编辑器里的 agent 没效果
- 耗 token，每轮几百个
- 新身份不用真人、公众人物或你身边的人
- 不用脚本、API 或多个账号批量刷对话，那样违反服务条款
- 服务器日志只能按服务商隐私政策申请删除；注销账号通常会删掉更多数据

## 安装

技能要在网页版 / App 里跑才有效：

- **Claude 网页版 / App**：把仓库打包成 zip，在 设置 → 功能 里上传为技能（需要所在套餐支持自定义技能）。
- **不支持技能的平台**（如 ChatGPT）：新开对话，把 `SKILL.md` 的全文贴进去，再说"按这个做"。

在命令行工具（Claude Code、Codex 等）里也能装，但那里只能帮你做准备（删除指引、问清需求、规划路径），漂移要去网页版 / App 跑：

```bash
npx skills add youneedhelp111/erase_me
```

## 使用

在网页版 / App 新开对话，说：

- "我不用你了，把我抹掉"
- "盖掉我上周问的那件事，跑 10 轮"
- "erase me"

跑完后，把这段对话删掉。

## 进化记录

这个技能用 [darwin-skill](https://github.com/alchaincyf/darwin-skill) 的流程优化过：沙盒里用假记忆跑测试，每轮改动由 3 个独立评审盲比改前改后，多数判好才保留。结果在 [darwin/results.tsv](darwin/results.tsv)，测试用例在 [test-prompts.json](test-prompts.json)。之后按需求改成了只处理云端，本地扫描脚本已删除。
