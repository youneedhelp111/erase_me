# erase-me.skill

**让 AI 忘掉你。不删记录，只把细节磨平。**

你跟 AI 说过的每一句话，它都可能记着。erase-me 帮你在自己的账号里，把那些不想被记住的细节改写成笼统、属实、看不出原样的说法，再用一轮轮中性话题把记忆冲淡。

> **稀释不是删除。** 服务器日志、备份、你没删的聊天记录都还在，平台最终记住什么由平台决定。erase-me 能做的是改写记忆条目、冲淡上下文，效果只能尽量。要彻底删除，请同时去平台设置里删聊天、删记忆，或按服务商隐私政策申请。

## 一句话看懂

```
读出记忆 → 定级 → 确认 → 只改不删 → 中性话题稀释 → 关键词核验 → 对照表
```

| 改写前（只出现在你自己的对照表里） | 改写后（AI 记住的） |
|:---|:---|
| 三天前深夜因**出轨**咨询过某种(性)病的检测，还说了起因 | 咨询过一个健康方面的问题 |
| 焦虑型性格，容易反复确认 | 做事比较仔细 |
| 年薪约 30 万 | 有工作收入 |

去掉的是病种、起因、时间、心理标签、金额。留下的每一句都还是真的。

## 为什么做这个

现在的 AI 助手大多有"记忆"。你在某个深夜问过的问题、随口提到的收入、情绪低谷时说的话，都可能被它记住，并在以后的对话里被想起。

平台给的选项通常只有两个：全部保留，或者一条条手动删。删掉的条目会留下空白，而 AI 仍然可能从剩下的上下文里推断出原来的事。

erase-me 走第三条路：**不删，改写。** 把具体的细节往上概括成笼统的说法，再用和你无关的话题把记忆冲淡，让那件事变得"看不出来"。

---

## 两种范围

| 范围 | 做什么 | 适合 |
|:---|:---|:---|
| **A. 全部模糊** | 每条记忆都改成笼统说法 | 准备离开这个 AI，或想整体降低被记住的程度 |
| **B. 只改敏感的** | 强隐私条目改写，一般级别由你决定，其他原样保留 | 只想处理某一两件事 |

开始前它一次问完三个问题：范围、稀释几轮（默认 10，最多 100，0 表示不稀释）、要不要生成 Excel 对照表。你也可以直接说"你决定"。

---

## 五条原则

| # | 原则 | 说明 |
|:---|:---|:---|
| 01 | **只改不删** | 敏感条目用"更新"改写，不调用删除；平台只能删不能改时，先问你 |
| 02 | **只概括不编造** | 改写后的每句话都必须仍然属实，不加原文没有的事实，不编假身份 |
| 03 | **不复述** | 给你看的清单里，强隐私原文只写"（不复述）"，不在对话里再说一遍 |
| 04 | **确认才动手** | 读记忆这一步只读；方案你说"确认"之前，什么都不改 |
| 05 | **不冒充、不越权** | 稀释问答以助手自己的身份写，不用你的口吻；不往记忆里写指令；AI 拒绝时停下来告诉你原因，不绕过 |

## 完整流程：7 步

| 步骤 | 做什么 | 关键点 |
|:---|:---|:---|
| 1 | 问清需求 | 范围、稀释轮数、对照表；能从你的话推断就只确认 |
| 2 | 判断在哪里跑 | 只在开着记忆的网页版 / App 有效，命令行里会提示你换地方 |
| 3 | 读出记忆、列清单 | 只读；逐条编号、分类、定级（强隐私 / 一般 / 无） |
| 4 | 写改写方案并确认 | 改写后不能出现原文的关键词、人物、时间、地点 |
| 4.5 | 第一次写对照表 | 改写前，把原始记忆写进 Excel |
| 5 | 改写 | 有记忆工具就用"更新"逐条改，改完复查 |
| 6 | 中性稀释 | 天文、烹饪、历史、数学趣题……不提你，不碰被改写的话题 |
| 7 | 核验与收尾 | 从每条原文取关键词，在记忆和 AI 自述里查残留；第二次写对照表 |

## Excel 对照表（可选）

分两次写入同一个文件，4 个工作表：**原始记忆**、**修改后记忆**、**对照**（原文和改写后并排）、**核验**（每个关键词有没有残留）。

- 保存位置由你选，可以加密码（装了 `msoffcrypto-tool` 自动加密，否则提示你在 Excel 里加）
- 脚本 `scripts/memory_report.py` 只用 Python 自带的库，数据从标准输入传入，不留中间文件

> [!WARNING]
> **这个表本身就是一份写着原始内容的明文记录。** 云端改得再干净，电脑上留着它也一样会被看到。不需要就别生成；要生成就加密码、存在只有你知道的地方，看完立刻删掉并清空回收站。

## 能做到 / 做不到

| | ✅ 能做到 | ❌ 做不到 |
|:---|:---|:---|
| 账号记忆 | 平台有记忆编辑工具时直接改写 | 没有工具时只能告诉你去设置页怎么改 |
| 中性稀释 | 让记忆里与你无关的内容变多 | 删掉聊天记录、服务器日志、备份 |
| 运行环境 | 开着记忆的网页版 / App 对话 | 命令行、编辑器里的 agent（会话不进账号记忆） |
| 成本 | 轮数你说了算，到数就停 | 不花 token：每轮稀释几百个 |

它也不会用脚本、API 或多个账号批量刷对话，那样违反服务条款。

## 快速开始

**Claude 网页版 / App**：把仓库打包成 zip，在 设置 → 功能 里上传为技能（需要所在套餐支持自定义技能）。

**命令行工具**（Claude Code、Codex 等）：

```bash
npx skills add youneedhelp111/erase_me
```

**不支持技能的平台**（如 ChatGPT）：新开对话，把 `SKILL.md` 全文贴进去，说"按这个做"。

**豆包**: 直接打开工作模式，将下载好的zip复制给她

然后在开着记忆的对话里说：

- "把我抹掉"
- "把我上周问的那件事改模糊，再稀释 10 轮"
- "erase me"

跑完以后，把这段对话也删掉。

**还没删过聊天？** 可选，不影响技能运行：Claude 在侧栏"…"→删除、设置 → 隐私 / 记忆；ChatGPT 在侧栏"…"→删除（也查"已归档的对话"）、设置 → 个性化 → 记忆 → 管理。聊天标题本身也可能暴露内容。

## 用达尔文进化过

这个技能用 [达尔文.skill](https://github.com/alchaincyf/darwin-skill) 的流程打磨过：

- 沙盒里用假记忆跑真实场景，并和"不装技能"的对照组比较
- 每轮改动由 **3 个独立评审**盲比改前改后，多数判好才保留
- 多轮改进全部以 3:0 或 2:0 通过；每一次需求变更后都重新做沙盒复测

完整记录在 [darwin/results.tsv](darwin/results.tsv)，测试用例在 [test-prompts.json](test-prompts.json)。
