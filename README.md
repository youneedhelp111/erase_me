# erase-me：让 AI 忘掉你

一个 Agent Skill（`SKILL.md` 格式）。它帮你看清 AI 助手在本机记下了你哪些事，再由你决定哪些删除、哪些模糊化、哪些改写。

## 它能做什么

先问你想抹除到什么程度：

| 模式 | 结果 |
|---|---|
| A. 清空 | 全部删除，助手对你一无所知 |
| B. 只留美好 | 删掉难受、尴尬、敏感的内容，留下开心的回忆和有用的偏好 |
| C. 清空并填充 | 全部删除后写入与你无关的中性内容（不编造关于你的假经历，填充块带 `erase-me filler` 标记，方便以后再删） |

然后：

- 盘点 AI 助手在本地保存的关于你的内容：记忆文件、输入历史、会话记录、使用痕迹
- 按类别列清单：身份信息、健康与情绪、人际关系、财务、位置、搜索历史……
- 每条由你选择：保留 / 删除 / 模糊化 / 改写
- 先给你看改动预览，你说"确认"才执行
- 执行完清理技能自己留下的临时文件，也不会在记忆里写下"你删了什么"

## 它做不到什么（请先读）

技能只能改**助手够得着的地方**：

- ✅ 本机文件：如 `~/.claude/`、`~/.codex/`、项目里的 `CLAUDE.md` / `AGENTS.md`
- ✅ 当前会话里提供了编辑接口的记忆工具
- ❌ 服务商服务器上的日志和备份
- ❌ 网页版 / App 里的聊天记录和"记忆"（需要你在设置里自己删）
- ❌ 其他设备、其他账号上的数据
- ❌ 已经被用于训练的数据

所以它是"清理本地记忆"的工具，不是"从互联网上抹掉你"的工具。

## 安装

把仓库克隆到你所用工具的 skills 目录，例如：

```bash
git clone https://github.com/youneedhelp111/erase_me ~/.claude/skills/erase-me
```

## 使用

对助手说：

- "忘掉我"
- "看看你记了我什么，帮我删掉一些"
- "把我和前任有关的记忆都删了"
- "erase me"

## 扫描器

`scripts/scan_memory.py` 是只读的，可以单独用：

```bash
python scripts/scan_memory.py
python scripts/scan_memory.py -k 关键词
python scripts/scan_memory.py --json
```
