# erase-me：让 AI 忘掉你

一个 Agent Skill（`SKILL.md` 格式）。它先问清你的全部需求，再做两件事：

1. **本地删除**：AI 助手存在你电脑上的记忆、输入历史、会话记录，按你的选择删除、模糊化或改写。
2. **云端稀释**：在你自己的账号里，助手和自己进行多轮与你无关的问答（天文、烹饪、历史……），并把这些无关内容写进记忆工具，让平台的记忆功能更少想起你。

## 它会先问你

1. 范围：只清本地 / 只处理云端 / 都要
2. 深度：

| 深度 | 结果 |
|---|---|
| A. 清空 | 全部删除，变成空白 |
| B. 只留美好 | 删掉难受、尴尬、敏感的内容，留下开心的回忆和有用的偏好 |
| C. 清空并填充 | 全部删除后用与你无关的中性内容填满（不编造关于你的假经历） |

3. 特别想忘掉的话题（可选，只用于本地扫描）
4. 云端稀释跑几轮（默认 10，最多 30）

之后每一步改动都会先给你看预览，你说"确认"才执行。结束时清理技能自己的临时文件，也不会在记忆里写下"你删了什么"。

## 先读：它能做到多少

| | 能做到 | 做不到 |
|---|---|---|
| 本地 | 真删：`~/.claude/`、`~/.codex/`、项目里的 `CLAUDE.md` / `AGENTS.md` 等 | 别的设备上的数据 |
| 云端记忆工具 | 当前对话里有能编辑账号记忆的工具时，真删条目 | 没有这类工具就只能告诉你去设置页删 |
| 云端稀释 | 让记忆功能里"与你无关"的内容变多 | **稀释不是删除**：原来的聊天记录、服务器日志、备份都还在；平台怎么生成记忆由平台决定，效果没法保证 |
| 其他 | | 已用于训练的数据、其他账号 |

几点提醒：

- 稀释只对开着记忆功能的网页版 / App 对话有用。在命令行或编辑器里跑，会话不进账号记忆，这一步没效果。
- 稀释要消耗 token，每轮几百个。
- 想真正删掉云端内容，最有效的还是自己动手：Claude 在 设置 → 隐私 / 记忆，ChatGPT 在 设置 → 个性化 → 记忆 → 管理，再删掉相关聊天；服务器日志只能按服务商的隐私政策申请删除。
- 技能不会用脚本或多个账号批量刷对话，那样可能违反服务条款。

## 安装

它是标准的 Agent Skill，任何支持 `SKILL.md` 的助手都能用。

**一行安装（自动识别你在用的工具）：**

```bash
npx skills add youneedhelp111/erase_me
```

**手动安装：** 把仓库克隆到对应工具的 skills 目录，目录名用 `erase-me`。

| 工具 | 用户级 skills 目录 |
|---|---|
| Claude Code | `~/.claude/skills/` |
| Codex | `~/.codex/skills/` |
| Cursor | `~/.cursor/skills/` |
| Gemini CLI | `~/.gemini/skills/` |
| 其他 | 查看该工具文档里的 skills 路径 |

**不想安装：** 直接把 `SKILL.md` 的内容贴给助手，让它照着做也行。

## 使用

对助手说：

- "忘掉我"
- "看看你记了我什么，帮我删掉一些"
- "把我和前任有关的记忆都删了"
- "稀释一下我的云端记忆"
- "erase-me 稀释 10 轮"（在网页版 / App 新开的对话里直接开始稀释）
- "erase me"

## 扫描器

`scripts/scan_memory.py` 是只读的，可以单独用：

```bash
python scripts/scan_memory.py
python scripts/scan_memory.py -k 关键词
python scripts/scan_memory.py --json
```
